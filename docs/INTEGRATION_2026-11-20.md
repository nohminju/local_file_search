## 후속 요청 반영 — 필터 후 RRF

사용자가 이번 작업 도중 원본 유사도 확인 → 관련성 낮은 결과 필터링 → RRF 결합을 요청했습니다. 원본 폴더에서 가져온 기준 초과 비율 정렬은 최종 코드에서 RRF로 교체했습니다.

1. 본문과 이미지를 각각 같은 모델 공간의 쿼리로 검색해 원본 코사인 유사도를 구합니다.
2. 각 목록에서 파일별 최고 청크만 남기고 원본 점수가 본문 0.4 / 이미지 0.2 미만이거나 비유한 값인 결과를 제외합니다.
3. 필터 통과 파일을 원본 점수순으로 다시 1위부터 정렬합니다. 동점은 경로 순서입니다.
4. `RRF(file) = Σ 1 / (k + rank)`로 결합합니다. 기본 k=60이고 같은 파일이 두 목록에서 통과하면 두 기여를 더합니다. 원본 점수 크기를 RRF에 직접 더하지 않습니다.
5. RRF 내림차순 정렬 후 내용 해시 중복을 제거하고 top_k로 제한합니다. RRF 동점은 경로 순서입니다.

예: 본문만 1위면 1/61 ≈ 0.016393, 양쪽 모두 2위면 2/62 ≈ 0.032258로 후자가 앞섭니다. 이는 유사도나 확률이 아닙니다. 표시용 원본 점수는 RRF 기여가 큰 쪽을 선택하고 동점이면 본문입니다. 양쪽 원본 점수는 결과 객체에 보존합니다.

본문 0.4 하한의 새 모델 적정성 미검증 상태는 그대로입니다. 하한 필터가 실제 무관 결과를 전부 구분한다고 보장하지 않습니다. 필터·RRF 회귀 검증을 포함한 최종 테스트 결과는 활동 기록에 추가합니다.
