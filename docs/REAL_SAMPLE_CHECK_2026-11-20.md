# v3 실제 샘플 검색 확인 — 2026-11-20

## 결론

**고양이 사진이 무관한 문서보다 먼저 나오는지는 실패했습니다.** 이미지 단독 순위는 맞지만 통합 순위에서 문서 본문의 높은 점수에 밀립니다. RRF 중복 가산은 제거됐으나 새 OpenCLIP 본문 모델의 점수 분포와 기존 하한·선형 보정만으로는 해결되지 않았습니다. 테스트 대역의 회귀 통과를 실제 검색 품질 통과로 해석하면 안 됩니다.

본문 검색은 데이터베이스 질의에서 관련 문서 1위, 동적계획법 질의에서 해당 문서 3위였습니다. 딥러닝 문서는 5위이고 무관한 PPTX가 앞서는 오류가 남습니다. 원문 청크를 그대로 넣은 진단에서는 해당 데이터베이스·동적계획법 문서가 각각 1위였으며 이는 의미 검색 품질의 독립 평가가 아닙니다.

## 고양이 사진이 밀리는 이유

`누워있는 고양이`에서 Test2.jpg 원본 이미지 점수는 0.260748, 정렬값은 0.075935입니다. 딥러닝 응용.pdf는 본문 0.500008, 이미지 0.187344, 최종 정렬값 0.166681로 사진보다 앞섭니다. 두 점수를 더해서가 아니라 본문 점수 하나만으로 앞서는 상태입니다.

본문 0.4는 이전 SentenceTransformer 본문 모델의 초기값입니다. 현재 OpenCLIP 본문 검색은 무관한 문서에도 높은 점수를 주었으며, 최댓값 결합만으로 모델 오판을 교정할 수 없습니다. 한 질의에 맞춰 하한만 올려 성공처럼 만들지 않았습니다. 본문 모델 선택·점수 보정·독립 정답 세트 평가가 후속 과제입니다.

## crops 확인

`encode_with_crops()`는 전체+사분면의 벡터를 반환하지만 현재 서비스는 encode_batch를 호출하므로 이번 결과는 crops 미적용 기준입니다. FAISS는 벡터 행마다 메타데이터가 필요하며 원본 파일·페이지 정보를 각 crop 행에 연결해야 합니다. 함수·FAISS 대역 테스트는 있으나 실제 crops 검색 품질은 이번에 측정하지 않았습니다. 사용자는 현황 검토를 질문했으며 활성화 변경은 요청하지 않았습니다.
