## 8. GUI 표시와 직접 비교

GUI의 일치도는 팀원이 넣은 `(원본점수-0.15)/(0.32-0.15)×100`을 0~100으로 제한한 표시입니다. 원본 0.32 이상은 모두 100%로 보입니다. 이 보고서는 GUI 환산 % 대신 원본 점수로 비교했습니다.

직접 실행할 원본 방식은 [nohminju/local_file_search의 compare 브랜치](https://github.com/nohminju/local_file_search/tree/compare)에 게시했습니다. 기준 main은 0bf2242이고 Python 파일 40개가 원본과 같습니다. 이후 원본 main에는 import 경로 수정과 앱에서 쓰지 않는 search_combined 삭제가 있었으나 본문·이미지 개별 검색과 서비스 번역 흐름은 실험 기준과 같습니다. 새로운 폴더 전체에서 실모델 평가를 재실행한 것은 아닙니다.

이 PC의 비교 폴더는 C:\Capstone\document-search-main-compare, 통합본은 C:\Capstone\document-search-demo-v3입니다. 두 방식에서 같은 test_esset 폴더·검색 모드·질의를 선택하세요. 비교 폴더의 COMPARE_GUIDE.md와 [현재 통합본 실행 안내](../README.md)를 참고하세요. 개인 .env는 게시하지 않고 .env.example만 compare 브랜치에 포함했습니다.
