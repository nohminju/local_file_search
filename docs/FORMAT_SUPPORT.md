# 파일 형식별 지원

| 형식 | 현재 동작 |
|---|---|
| PDF | 추출 가능한 본문 검색 |
| PPTX | 글·표 본문 검색, 내부 이미지 검색(임시 구현) |
| JPG / JPEG / PNG / WEBP | 이미지 읽기·인코딩·유사도 검색(임시 구현) |
| PPT / HWP / HWPX | 미지원 |
| TXT / 코드 파일 / DOCX / 노트북 | 현재 스캐너가 수집하지 않음 |

PDF 페이지 이미지화·OCR이 없어 스캔 PDF만으로는 본문 검색을 확인하기 어렵다.
PPTX 로더는 슬라이드당 마지막 이미지 하나만 남기며 슬라이드 전체를 이미지로 만들지 않는다.
DB 저장 여부와 파일 본문을 해석할 수 있는지는 별개다.

PDF·PPT·한글 전체 지원은 향후 목표다. 현재 데모는 PDF·PPTX 본문 검색과 이미지 유사도 검색(임시 구현)을 제공한다.
