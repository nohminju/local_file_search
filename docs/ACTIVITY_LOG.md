## 2026-11-06 — 팀원 코드 검토와 FAISS 검색 연결

### 작업을 시작한 이유

팀원이 구현한 파일들을 다시 받은 뒤, 기존 실행 코드와 제대로 연결되어 있는지 확인할 필요가 있었다. AI에게 내 담당 연결 코드를 중심으로 점검을 요청했다. 검토 범위는 `document-search-demo-v1` 폴더이며 기준 코드는 `document-serch-demo-v1` 브랜치의 `1d368f5`다.

이 기록에 해당하는 연결 코드 수정과 문서 정리는 아직 커밋하지 않은 상태에서 작성했다. 앞서 `service-merge`에서 만든 `f956c3b` 커밋과는 별개다.

### 내가 확인하고 판단한 부분

- 실행 중 `open_clip` 모듈이 없다는 오류를 확인하고, 이 라이브러리가 어떤 코드에 필요한지 질문했다. AI의 코드 확인 결과를 통해 이미지와 검색 문장을 같은 모델로 벡터화하는 데 사용된다는 설명을 받았다.
- 팀원 코드까지 모두 바꾸기보다는 내 담당 코드만 수정하고, 팀원 코드의 문제는 전달 문서로 정리하도록 범위를 정했다.
- FAISS가 연결된 뒤에는 기존 임시 이미지 비교 코드를 없애도 된다고 판단해 삭제를 요청했다.
- ‘파일별 중복 제거 후 상위 5개 반환’이 어디서 처리되는지 설명을 요청했다. `DocumentSearch.search()`에서 처리하며, 5개는 기본값이고 `top_k`로 바꿀 수 있다는 설명을 받았다.
- 불필요하게 구조를 늘리지 않고, 중복 코드와 주석을 정리하도록 요청했다.
- FAISS의 이전 인덱스 파일이 남는 문제가 현재 실행에도 영향을 주는지 여러 차례 질문했다. 현재 앱은 save/load를 호출하지 않는다는 설명을 확인한 뒤, 이 문제는 현재 수정 요청에서 빼고 ‘기능 업데이트 시 주의’로 분리하기로 했다.

위 내용은 내가 대화에서 질문하고 결정한 사항이다. 코드 전체를 직접 작성하거나 아래 자동 테스트를 직접 실행한 것으로 기록하지 않는다.

### AI가 검증한 부분

- 로더·인코더·DB·FAISS와 앱의 호출 흐름을 읽고, FAISS 파일은 있지만 검색 서비스에서 사용하지 않는 상태를 확인했다.
- 기존 테스트를 실행해 없어진 `database.db_manager`를 가져오는 오류와 GUI 라이브러리 누락을 확인했다. GUI 테스트도 이전 화면 구조를 기준으로 작성되어 있었다.
- 그림 2개가 있는 PPTX 슬라이드를 만들어 로더가 이미지 1개만 반환하는 현상을 재현했다.
- 실제 SQLite 저장·조회로 동일 경로 갱신 동작을 확인했다. DB 연결이 닫히지 않아 파일 정리 오류와 경고가 발생하는 것도 확인했다.
- FAISS를 같은 폴더에 두 번 저장하는 실험에서 이전 이미지 인덱스와 새 메타데이터가 맞지 않아 `IndexError`가 발생하는 것을 재현했다. 이 실험은 현재 앱 실행과 별도로 진행했다.
- PDF 이미지 열거 오류가 이미 추출한 본문까지 버릴 수 있는 부분을 코드에서 확인했다. 실제 문제 PDF로 재현한 것은 아니다.

### AI가 수정·통합한 부분

- `app.py`에서 팀원 `FaissManager`를 만들어 검색 서비스에 전달하도록 연결했다.
- `connection/service.py`에서 본문·이미지 벡터와 청크를 각각 FAISS에 전달하고, 검색 결과의 파일 경로를 SQLite 파일 정보와 연결했다.
- 검색 결과는 파일별 최고 점수 하나만 남긴 뒤 기본 5개를 반환하도록 유지했다. 본문 검색과 이미지 검색의 점수는 합치지 않았다.
- 사용하지 않는 임시 이미지 비교 함수와 전용 테스트를 삭제했다.
- 이미지 인코딩 분기의 중복을 줄이고, 연결 코드·GUI에서 동작을 그대로 풀어쓴 주석을 정리했다. GUI 작업 큐는 유지했다.
- 테스트의 DB import와 중복 갱신 기대값을 수정하고, GUI 작업 큐에 맞게 테스트를 변경했다. requirements에 `faiss-cpu`를 추가했다.
- README, 연결 순서, 폴더 역할, DB 설명, 파일 형식 지원 및 팀원 전달 문서를 현재 동작에 맞췄다.

팀원 로더·인코더·SQLite·FAISS 내부 구현은 수정하지 않았다. 저장·복원이나 새 통합 검색 기능도 추가하지 않았다.
